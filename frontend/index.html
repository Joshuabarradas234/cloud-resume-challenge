The site you're reading now.

  • Private S3 origin behind CloudFront (Origin Access Control), custom domain over HTTPS with an ACM certificate.
  • Visitor counter: API Gateway → Lambda → DynamoDB, using an atomic update so no visit is ever lost under concurrency.
  • 100% Terraform with remote state; GitHub Actions CI/CD that tests, applies, syncs and invalidates on every push — authenticating to AWS via OIDC, with no long-lived keys.
